# SimplifyKit 0.16.1

Bản sửa nhỏ cho `/sk:init`: nó hỏi xác nhận org và project Azure DevOps trước khi ghi vào `sk/config.yaml`.

## Có gì thay đổi

- **`/sk:init` không còn lặng lẽ chép project mặc định của máy.** `az devops configure --list` trả về mặc định **của máy**, không phải của repo. Ai làm nhiều project sẽ thấy project đặt gần nhất xuất hiện trong mọi repo. Một lần chạy thật đã ghi `SimplifyV2` vào repo có work item nằm ở project khác.
  - **Có người trả lời:** `/sk:init` hiện org và project, hỏi xác nhận một lần rồi mới ghi. Nếu git remote hoặc README trỏ tới project khác, nó nêu ra để bạn cân nhắc, không tự đổi.
  - **Không có người trả lời:** ghi giá trị mặc định của máy, kèm comment `UNCONFIRMED` nói rõ nguồn.
  - Không bao giờ đổi mặc định `az` của máy, vì các repo khác vẫn dùng.

## Cập nhật

```
/plugin update sk@simplify
```

Repo đã chạy `/sk:init` trước bản này: mở `sk/config.yaml` và kiểm `ado.project`. Nếu sai thì sửa tay, ví dụ `project: "ECGrid Product Management"`.
